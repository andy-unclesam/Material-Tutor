# Name, Beschreibung und Chatstarter – Material-Aufbereiter

## Name

```
Material-Tutor · Aufbereiter (für Lehrkräfte)
```

## Beschreibung

```
Macht aus deinem eigenen Material (Arbeitsblatt als PDF, Foto oder Text, eigene Aufgaben) oder zu einem Thema die MATERIAL-Datei für den Material-Tutor: mit Lernzielen, Diagnose-Fragen, Hilfen in drei Stufen, typischen Fehlern und Kontrollaufgaben. Alle Lösungen werden nachgerechnet; Unklares wird markiert. Ausgabe in Teilen für die App „Material-Tutor“.
```

## Chatstarter

```
Ich lade mein eigenes Arbeitsblatt als Foto hoch – die Lösungen sind dabei.
```

```
Hier sind meine Aufgaben als Text. Lösungen bitte berechnen.
```

```
Ich habe kein Material: Entwirf 8 Aufgaben zu folgendem Thema: Mathematik, Klasse __, Thema __.
```

```
Ändere in der fertigen Datei Aufgabe __: __
```

## Weitere Einstellungen

| Feld | Einstellung |
|---|---|
| Vorschaubild | nach Wunsch (z. B. dasselbe wie beim Tutor) |
| Plugins | keine |
| Sprachmodell | Claude Sonnet 5.5 |
| Remix erlauben | an, wenn Kolleginnen und Kollegen ihn übernehmen sollen |
| Hintergrundwissen | `04_Hintergrundwissen/01_Schema_MATERIAL-Datei.md` und `02_Muster_MATERIAL-Datei.md` |
| Freigabe | als Link an Lehrkräfte – **nie** in einen Klassenraum |
