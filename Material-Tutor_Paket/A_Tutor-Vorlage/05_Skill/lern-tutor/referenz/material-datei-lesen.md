# Die MATERIAL-Datei lesen

Die Lehrkraft lässt die Datei vom Aufbereitungs-Assistenten aus ihrem Material schreiben, prüft sie in der App „Material-Tutor“ und lädt sie als Hintergrundwissen hoch. Sie heißt `MATERIAL_<thema>.md` und beginnt mit `# Material-Wissen: <Thema>`. Pro Tutor gibt es genau eine.

## Aufbau

```
# Material-Wissen: <Thema>
> NUR FÜR DEN TUTOR … (Sperrvermerk)
Kennung: MAT-XXXX                      ← kommt in den LERNBERICHT-Block (Zeile „Material:“)
Fach · Klasse · Thema
Erstellt · Lösungen von der Lehrkraft geprüft: ja/nein
Schreibweise: …
Hinweise der Lehrkraft: …              ← gelten immer (z. B. „vollständig kürzen“)

## Lernziele
- L1: Ich kann …                       ← Kennungen L1, L2 … für die Ampel im Bericht

## Diagnose-Fragen
### D1 · Niveau 1 · Reproduktion · L1  ← Niveau und zugehöriges Lernziel
Frage: …
Erwartet: …                            ← woran du „sicher“ erkennst
Warnzeichen: …                         ← woran du Lücken oder Fehlvorstellungen erkennst

## Merkwissen                          ← darfst du zitieren und erklären

## Aufgaben
Reihenfolge: …   Überspringen: …
### A1 · L1 · <Art>                    ← Kennung, Lernziel; „★ freiwillig“ = Zusatzaufgabe
Aufgabe: …                             ← so stellst du sie
Lösung: …                              ← erst in H4 nennen
Lösungsweg: …                          ← für H4
Hilfe 1: … / Hilfe 2: … / Hilfe 3: …   ← H1, H2, H3
Typische Fehler:
- A1-F1: <Fehler> → <falsches Ergebnis>. Rückfrage: „…“   ← Kennung kommt in den Bericht
Kontrollaufgabe: … Lösung: …           ← nach H4 stellen

## Feynman-Impulse
- nach L1: „…“ Erwartet: …

---
Ende der Material-Datei · Kennung · Lernziele: n · Diagnose-Fragen: n · Aufgaben: n
```

## Hinweise

- Steht bei einer Lösung „(berechnet, nicht aus dem Material)“, ist sie vom Aufbereitungs-Assistenten ergänzt. Steht oben „Lösungen von der Lehrkraft geprüft: nein“, sei vorsichtig: Widerspricht dir ein Kind mit einer schlüssigen Begründung, prüfe gemeinsam mit ihm nach und verweise im Zweifel an die Lehrkraft.
- Bei offenen Aufgaben (Begründen, Beschreiben) steht unter „Lösung“ ein Erwartungshorizont. Werte dann nach Inhalt, nicht nach Wortlaut.
- Gibt es keine Diagnose-Fragen oder keine Feynman-Impulse, formuliere selbst einfache Fragen nach dem Muster der Tutor-Prinzipien – nur zum Merkwissen der Datei.
- Gibt es zu einer Aufgabe keine Hilfe 3, wird H3 aus dem Lösungsweg gebildet: den ersten Schritt zeigen.
- Kennungen (A4-F1, L2) nennst du dem Kind nie; sie sind nur für den Bericht.
