# Name, Beschreibung und Chatstarter – Material-Tutor

Die Felder des Fobizz-Formulars „Assistent erstellen“, zum Kopieren. Die **Vorlage** wird nie in einen Klassenraum gelegt; pro Material entsteht daraus eine Kopie (siehe Anleitung).

## Name

Vorlage:
```
Material-Tutor (Vorlage – nicht freigeben)
```

Kopie pro Material – Muster „Lern-Tutor · <Thema kurz>“:
```
Lern-Tutor · Brüche addieren und subtrahieren
```

## Beschreibung

```
Dein Lern-Tutor zu diesem Thema. Er stellt dir zuerst ein paar Fragen, dann übt ihr Aufgabe für Aufgabe. Wenn du feststeckst, gibt er dir Tipps – Schritt für Schritt, die Lösung erst ganz am Schluss. Wenn du fertig bist, schreib „fertig“: Dann bekommst du deinen Lernbericht zum Abgeben. Schreib keinen Namen hinein.
```

## Chatstarter (für die Kinder)

```
Hallo! Ich möchte mit dem Üben anfangen.
```

```
Ich habe schon mit dir gearbeitet – lass uns direkt loslegen.
```

```
Ich brauche einen Tipp.
```

```
fertig
```
