# Der Material-Tutor

Ein sokratischer KI-Tutor in Fobizz, der mit beliebigem Material arbeitet – eigenes Arbeitsblatt, eigene Aufgaben oder nur ein Thema – und kein interaktives Arbeitsblatt braucht: Diagnose-Fragen auf drei Niveaus, Aufgabe für Aufgabe, Hilfe in vier Stufen, Erklären in eigenen Worten und am Ende ein Lernbericht zum Abgeben. Ein zweiter Assistent, der Aufbereiter, schreibt aus dem Material die Wissensdatei `MATERIAL_….md`; die App prüft sie und wertet die Lernberichte der ganzen Klasse aus.

**Beitrag:** https://andreas-hemmeter.de/Material-Tutor/

| Pfad | Inhalt |
|---|---|
| `index.html` | der Beitrag mit Anleitung |
| `app/` | die App: ① MATERIAL-Datei zusammensetzen und prüfen, ② Lernberichte auswerten (läuft vollständig im Browser, keine Netzverbindung) |
| `bilder/` | Abbildungen zum Beitrag (Beispieldaten, erfunden) |
| `material/Material-Tutor_Paket.zip` | Anleitung, Instruktionen, Skill `lern-tutor`, Wissensdateien, Chatstarter, Bild, Beispiel-Datei, Aufbereiter und App zum Herunterladen |
